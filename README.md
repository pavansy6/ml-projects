
# 🧠 Machine Learning Projects

This repository contains a collection of small, beginner-friendly Machine Learning projects.  
Each folder focuses on a specific ML model, with a Jupyter Notebook explaining the workflow, implementation, and results.

---

## 📂 Repository Structure
```
ml-projects/
│
├── README.md                 # Main repo overview (this file)
├── requirements.txt          # Common dependencies
│
├── linear_regression/        # Predict continuous values (e.g., house prices)
├── logistic_regression/      # Binary classification (e.g., pass/fail, spam/ham)
├── decision_tree/            # Tree-based classification/regression
├── random_forest/            # Ensemble learning with multiple trees
└── svm/                      # Support Vector Machine for classification
```

---

## 🚀 Getting Started

### 1. Clone this repo
```bash
git clone https://github.com/pavansy6/ml-projects.git
cd ml-projects
```

### 2. Install dependencies
Make sure you have Python 3.8+ installed, then run:
```bash
pip install -r requirements.txt
```

### 3. Run the notebooks
Navigate to any project folder and open the notebook:
```bash
cd linear_regression
jupyter notebook linear_regression.ipynb
```
